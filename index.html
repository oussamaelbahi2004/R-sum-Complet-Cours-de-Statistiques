Exercice récapitulatif du cours (Bureau de poste) & Corrigé Numérique Complet

Énoncé (Page 58) : On observe $N = 100$ fois le nombre d'arrivées (variable $X$) de clients à un bureau de poste pendant un intervalle de temps (10 minutes). Questions : 1. Organiser ces données dans un tableau ($n_i, f_i, N_i^+, N_i^-, F_i^+, F_i^-$). 2. Calculer les valeurs de tendance centrale ($Mo, \bar{x}, Me$). 3. Calculer les valeurs de dispersion ($e, e_m, V_X, \sigma_X$) et tracer le diagramme en bâtons.

2. Paramètres de position (Tendance centrale) :

  • • Mode ($Mo$) : Plus grand effectif $n_3 = 25 \Rightarrow \mathbf{Mo = 3}$.
  • • Moyenne ($\bar{x}$) : $\bar{x} = \frac{1(16)+2(24)+3(25)+4(20)+5(7)+6(8)}{100} = \frac{302}{100} = \mathbf{3,02}$.
  • • Médiane ($Me$) : $F_2^+ = 0,40 < 0,5$ et $F_3^+ = 0,65 \ge 0,5 \Rightarrow \mathbf{Me = 3}$ (ou $\frac{x_{50}+x_{51}}{2} = \frac{3+3}{2} = 3$).

3. Paramètres de dispersion & Graphique :

  • • Étendue ($e$) : $e = x_{\max} - x_{\min} = 6 - 1 = \mathbf{5}$.
  • • Écart moyen ($e_m$) : $e_m = \frac{16|3-1|+24|3-2|+25|3-3|+20|3-4|+7|3-5|+8|3-6|}{100} = \frac{114}{100} = \mathbf{1,14}$.
  • • Variance ($V_X$) : $V_X = \left(\frac{16(1^2)+24(2^2)+25(3^2)+20(4^2)+7(5^2)+8(6^2)}{100}\right) - (3,02)^2 = 11,20 - 9,1204 = \mathbf{2,0796}$.
  • • Écart-type ($\sigma_X$) : $\sigma_X = \sqrt{2,0796} \approx \mathbf{1,442}$.
